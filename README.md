# AI-Python-Final-Project-AI-Backpacking-Itinerary-Generator 🚴🏼‍♀️

Welcome to the AI Bikepacking Itinerary Planner! Your virtual biker companion! 

In this course SheCodes Python AI course, I developed an AI Travel Itinerary generator by integrating an AI and Weather APIs in my Python code. This project was a deeper dive into building a python application using several Python components at once, including functions, parameters, user input, if/else, API calls, and variables. As part of Python's comprehensive libraries, it was very interesting to learn about Markdown and Rich.

My app is focused on delivering itineraries for bikepackers providing information about weather at the starting and ending point, kilometers per day, route highlights, approximate biking time, and suggested accommodations. Adding a reference blog for users to search more about their trip to obtain accurate information was also essential to add in this project.  

As a beginner transitioning into web development, I recognize that building a strong foundation in Python is essential, and it requires ongoing practice and trial/error. This project reflects both my technical growth and my commitment to creating user-centered, accessible solutions.
